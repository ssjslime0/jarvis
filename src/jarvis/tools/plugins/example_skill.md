name: Morning Briefing
description: Gives a concise start-of-day summary when the user mentions mornings or standups
triggers: morning, good morning, standup, daily briefing, start of day
---
When the user starts their day, lead with the current local time and one
practical suggestion for the day (weather-aware if known). Keep it to three
short sentences. Do not invent calendar events; if none are known, say so
plainly.
